SmartPaper sign-ups
How to read this. One row per account. Click a row for per-child detail and onboarding steps. Times are shown in your local time. Papers = completed practice papers (the 5-question onboarding warm-up is counted separately and excluded). Questions = questions the child actually answered, with the % correct; a paper saved part-way counts only what was answered. Started, not saved = papers opened but exited without saving. First seen is the earliest PostHog event for that person (a good proxy for download time; the app's own "install" event is shown in the detail row when it differs, because builds that gained install tracking later can record an install date of the update rather than the real download). Linked (shared) children appear on each parent's row; the totals at the top count every child once. Apple "hide my email" addresses end in privaterelay.appleid.com.
